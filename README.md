# Chronos Path - Frontend

Interface interativa em React para o guia histórico "Chronos Path".

## Tecnologias
- **Framework**: React + Vite
- **Mapa**: Leaflet + React-Leaflet
- **Animações**: Framer Motion
- **Ícones**: Lucide React
- **Estilo**: CSS Vanilla (Premium Glassmorphism)

## Configuração

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Certifique-se de que o backend está rodando em `http://localhost:3000` (ou atualize a `API_BASE` em `App.jsx`).

## Rodando a aplicação

```bash
npm run dev
```

## Funcionalidades
- **Mapa Interativo**: Visualização de pontos históricos baseada na localização do usuário.
- **Geolocalização**: Centralização automática e busca de segredos ao redor.
- **Painel de História**: Interface elegante com desfoque de fundo para leitura das narrativas geradas por IA.
